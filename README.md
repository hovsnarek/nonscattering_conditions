This file contains some calculations that appear in the paper "Higher-order necessary conditions for nonscattering" at https://arxiv.org/abs/2610.21338.
Specifically, the Maple code verifies the second formula in (3.7) as well as the formula in Remark 3.4.
It also verifies the simplifications of these formulas in the case of the ellipse. Namely, the second formula in (3.19) as well as the formula in Remark 3.10.
